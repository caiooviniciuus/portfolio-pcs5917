# Apresentações da PCS5917

O arquivo pcs5917-ia-adversarial.tex é um modelo de apresentação para a disciplina PCS5917 – IA Adversarial.

Ele é incluído pelo mestre em 02-mestrado/apresentacao-caio-ppgsi-usp.tex, que deve usar a definição \def\apuspperfil{poli}.

Para criar uma apresentação nova, copie o arquivo-modelo, renomeie-o e altere a linha \include correspondente no mestre.
